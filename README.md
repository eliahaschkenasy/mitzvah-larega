# מצווה לרגע

אתר עברי קטן שבוחר מצווה או מעשה טוב באופן אקראי, ומציג הסבר קצר וצעד מעשי להיום.

## האתר החי

[eliahaschkenasy.github.io/random-mitzvah](https://eliahaschkenasy.github.io/random-mitzvah/)

## הרצה מקומית

פתחו את `docs/index.html` בדפדפן, או הריצו שרת סטטי מתוך תיקיית `docs`.

## בדיקות

```bash
npm test
```

הבדיקות מוודאות שהעמוד מוגדר בעברית ובכיוון RTL, שכל קובצי האתר נטענים באופן יחסי, שהכפתור מגריל מצווה חדשה בלי לחזור מיד על הקודמת, ושקיימות התאמות לנגישות ולמובייל.

האתר מתפרסם באמצעות GitHub Pages מתיקיית `docs` בענף `main`.
