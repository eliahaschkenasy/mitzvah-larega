# מצווה לרגע

אתר עברי קטן שמגריל מצווה מתוך 613 המצוות שמנה הרמב״ם בספר המצוות. כל כרטיס מציג את סוג המצווה, מספרה ופתיח קצר מנוסח הספר.

## האתר החי

[eliahaschkenasy.github.io/random-mitzvah](https://eliahaschkenasy.github.io/random-mitzvah/)

## הרצה מקומית

פתחו את `docs/index.html` בדפדפן, או הריצו שרת סטטי מתוך תיקיית `docs`.

## בדיקות

```bash
npm test
```

הבדיקות מוודאות שהעמוד מוגדר בעברית ובכיוון RTL, שהמאגר כולל 248 מצוות עשה ו־365 מצוות לא־תעשה, שהכפתור מגריל מצווה חדשה בלי לחזור מיד על הקודמת, ושקיימות התאמות לנגישות ולמובייל.

מאגר המצוות מופק מנוסח ספר המצוות לרמב״ם שבספריא באמצעות `scripts/generate-mitzvot.ps1`.

האתר מתפרסם באמצעות GitHub Pages מתיקיית `docs` בענף `main`.
